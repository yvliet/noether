# Bookmarks

Bookmarks lets you pin your most important notes, canvas boards, searches, and folders for fast one-click access.

## 1. Overview
---

Instead of searching through folders every day, you can bookmark items you access frequently. Bookmarks live in the left sidebar and stay pinned across restarts.

## 2. Bookmark an Item
---

You can bookmark items in multiple ways:

- **From the File Tree**: Right-click any note, canvas, or folder and select **Bookmark**.
- **From the Active Editor**: Open the note options menu (`...`) in the top right corner and click **Bookmark Note**.
- **Via Hotkey**: Press `Ctrl+D` while viewing any note to bookmark it immediately.

## 3. Manage Bookmarks
---

1. Click the **Bookmarks** tab in the left sidebar.
2. Drag and drop bookmarks up or down to reorder them.
3. Right-click any bookmark to **Rename alias** or **Remove bookmark**.

## 4. Drag Bookmarks into Editor or Canvas
---

- Drag a bookmark from the sidebar directly into an open editor to insert a `[[Wikilink]]`.
- Drag a bookmark onto an open Canvas board to create a visual card for that note.

## 5. Keyboard Shortcuts & Commands
---

| Shortcut / Command | Action |
| :--- | :--- |
| `Ctrl+D` | Bookmark or unbookmark active note |
| `Alt+2` | Focus Bookmarks sidebar tab |
| `Command Palette → Bookmarks: Show bookmarks` | Open bookmarks list |

> [!NOTE]
> Bookmarks are saved in `.noether/bookmarks.json` inside your vault, so your bookmarks stay intact when switching devices.
