# Bookmarks

Pin frequent notes, canvases, and folders to the left sidebar for quick access.

## 1. Pinning Items
---

You can pin items from anywhere in the app:

- Press `Ctrl+D` while viewing any note to pin or unpin it.
- Right-click any file, folder, or canvas in the sidebar tree and choose **Bookmark**.
- Open the `...` menu in the note header and select **Bookmark Note**.

Bookmarks appear in the left sidebar under the Bookmarks tab. You can drag and drop them to reorder your pinned list, or right-click to assign a custom alias (e.g. rename a long file name to a short label).

## 2. Dragging to Editor & Canvas
---

Bookmarks work as draggable shortcuts:

- Drag a bookmark into an open note to insert a `[[Wikilink]]`.
- Drag a bookmark onto an open Canvas board to create an embedded note card.

All bookmark mappings are saved locally in `.noether/bookmarks.json`.
