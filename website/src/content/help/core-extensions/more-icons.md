# More Icons

More Icons lets you assign custom vector icons and colors to files and folders in your sidebar tree, making notes visually recognizable at a glance.

## 1. Overview
---

Instead of standard generic file and folder symbols, More Icons gives you access to thousands of curated glyphs from Hugeicons and Lucide icon sets. Custom icon assignments are saved locally in `.noether/icons.json`.

## 2. Change an Icon
---

1. Right-click any note, canvas, or folder in the left sidebar tree.
2. Click **Change icon**.
3. Search for a glyph (e.g. `book`, `code`, `star`, `terminal`, `archive`).
4. Select a color swatch or leave it neutral.
5. Click the icon to apply it immediately.

## 3. Set Auto-Rules for Folders
---

You can configure automatic icon rules based on folder paths or file extensions:

1. Open **Settings (`Ctrl+,`) → More Icons**.
2. Add a rule: for example, automatically give any file inside `Projects/` a folder badge icon, or give `.canvas` files a purple whiteboard glyph.
3. Click **Apply Rules**.

## 4. Reset or Remove Icons
---

- Right-click the file or folder in the sidebar tree.
- Select **Reset icon** to return to default system icons.

## 5. Keyboard Shortcuts & Commands
---

| Command | Action |
| :--- | :--- |
| `Command Palette → Icons: Set icon for active note` | Open icon picker for active note |
| `Command Palette → Icons: Reset all custom icons` | Clear custom icon cache |

> [!TIP]
> Custom icons also render on Canvas note cards and inside Backlinks search results.
