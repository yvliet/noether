# More Icons

Assign custom icons and colors to files, folders, and tabs in the sidebar so you can spot notes quickly without reading filenames.

## 1. Setting Icons & Colors
---

Right-click any note, folder, or canvas in the left sidebar and select **Change icon** (or run `Icons: Set icon for active note` from `Ctrl+K`).

- **Search Glyphs**: Browse thousands of icons from HugeIcons by name (e.g. `terminal`, `sparkles`, `book`, `code`).
- **Color Accents**: Pick a color swatch to tint the icon, or leave it neutral to follow your current theme colors.
- **Custom SVGs**: Paste raw SVG markup directly into the search bar if you want a custom glyph that isn't in the library.

To revert back to the default file or folder glyph, right-click and choose **Reset icon**.

## 2. Auto-Rules for Folders
---

If you keep specific categories in dedicated folders (like `Projects/` or `Archive/`), you don't have to set icons one by one.

In **Settings (`Ctrl+,`) → More Icons**, you can set path rules:

- Assign an icon to an entire directory (e.g. all notes inside `Projects/` get a hammer or folder badge).
- Match by extension (e.g. give all `.canvas` files a purple layout icon).

## 3. Storage
---

All custom icon mappings and rules are stored locally in `.noether/icons.json`. Icons also appear on Canvas cards, search results, and editor tab headers.
