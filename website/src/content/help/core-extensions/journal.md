# Daily Journal

Open or create date-stamped daily notes with a single hotkey (`Alt+J`) to log thoughts, scratch ideas, and track tasks.

## 1. Opening Daily Notes
---

Press `Alt+J` or click the journal calendar icon in the Action Rail:

- If today's entry already exists (e.g. `Journal/2026-09-19.md`), it opens in the active editor.
- If it doesn't exist yet, Noether creates it from your configured template.
- Use the arrow buttons in the note header to step forward or backward through days, or open the mini-calendar in the right sidebar to jump directly to any date.

## 2. Templates & Folder Setup
---

In **Settings (`Ctrl+,`) → Journal**, you can configure:

- **Target Folder**: Where daily files live (defaults to `Journal/`).
- **Date Format**: How filenames are formatted (e.g. `YYYY-MM-DD`).
- **Template File**: Pick a note (like `Templates/Daily.md`) to automatically prefill new entries with your habit checklists, daily headers, or reflection prompts.

Any `- [ ]` tasks you write inside a daily note automatically appear on your global Tasks dashboard (`Alt+T`).
