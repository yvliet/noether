# Daily Journal

Daily Journal creates and opens daily reflection notes with a single click, helping you log thoughts, track daily habits, and organize scratch notes by date.

## 1. Overview
---

Daily notes provide a dedicated scratchpad for each calendar day. Noether stores these notes in a designated folder (such as `Journal/` or `Daily/`) with date-stamped filenames (e.g. `2026-09-16.md`).

## 2. Open Today's Journal Note
---

- Click the **Daily Journal** icon in the Action Rail.
- Press `Alt+J` from anywhere in Noether.
- If today's note already exists, it opens immediately. If not, Noether creates it from your default template.

## 3. Navigate Between Dates
---

- **Calendar Navigation**: Open the right sidebar Journal panel to browse notes with a mini calendar widget.
- **Previous / Next Day**: Click the left or right arrows in the journal header to jump to yesterday's or tomorrow's entry.

## 4. Journal Settings & Templates
---

Open **Settings (`Ctrl+,`) → Journal** to configure your setup:

- **Journal Folder**: Choose where daily notes are stored (e.g. `Journal/` or `Life/Daily/`).
- **Date Format**: Standardize file names (e.g. `YYYY-MM-DD` or `YYYY/MM/DD`).
- **Template Note**: Specify a Markdown template note (e.g. `Templates/Daily Template.md`) to automatically prefill daily headers, task lists, and habit trackers.

## 5. Keyboard Shortcuts & Commands
---

| Shortcut / Command | Action |
| :--- | :--- |
| `Alt+J` | Open or create today's daily journal note |
| `Command Palette → Journal: Open yesterday's note` | Jump to yesterday's entry |
| `Command Palette → Journal: Open tomorrow's note` | Jump to tomorrow's entry |

> [!TIP]
> Combine Daily Journal with the Tasks extension. Any `- [ ]` checklist items you write in your daily notes automatically show up on your global Tasks board!
